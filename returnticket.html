RETURN TICKETS

Request a return for your tickets. Please note all returns are subject to organizer approval and our Return & Refund Policy.

Important: According to our Return & Refund Policy, refund eligibility, amounts, and deadlines are determined by the event organizer. If refunds are permitted, a 20% cancellation fee applies. Platform and service fees are non-refundable.

SUBJECT TO ORGANIZER APPROVAL

Request Refund

Submit a refund request to the event organizer. If approved, refunds will be processed minus 20% cancellation fee and non-refundable platform fees.

NOT AVAILABLE

Exchange Tickets

Ticket exchanges are not available through our platform. Please contact the event organizer directly for exchange options.

KEY POLICY POINTS

General Refund Policy

  • Refund eligibility determined by event organizer
  • Some events may be non-refundable
  • Refund deadlines set by organizer

User-Initiated Cancellations

  • 20% cancellation fee applies
  • Must comply with organizer policies
  • Platform fees non-refundable

Event Cancellation

If event is cancelled, organizer decides if refunds are offered. Any approved refunds issued by organizer, not Tanderrum Events.

Event Postponement

For postponed events, organizer determines if tickets remain valid for rescheduled date or if refunds will be offered.
